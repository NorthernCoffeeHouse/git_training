# Git 101

Chapter-by-chapter, hands-on material for learning Git from the command line. The course covers repository basics, commits, branches, collaboration, recovery, and releases.

## Start here

Open the [Git 101 page](pages/Git-101.html) and work through the interactive chapters in order. Each chapter includes commands and exercises; the final chapter is a capstone project.

## Repository files

- [index.html](index.html) — training library homepage and static-host entry point.
- [pages/Git-101.html](pages/Git-101.html) — Git 101 course page.
- [pages/Git-101.md](pages/Git-101.md) — full course and command reference.
- [assets/css/styles.css](assets/css/styles.css) — shared styles for both pages.
- [assets/js/home.js](assets/js/home.js) and [assets/js/app.js](assets/js/app.js) — homepage and course interactions.
- [.gitignore](.gitignore) — ignores build output, local tooling, secrets, and editor/operating-system files.
- [.gitattributes](.gitattributes) — keeps text files consistently normalized to LF line endings.
