# Training Library

Practical, chapter-by-chapter training for tools and ideas that power your work.

## Start here

- Open [Git 101](pages/Git-101.html) for hands-on command-line lessons.
- Read the [Survival Horror FPS field guide](pages/Unreal-Survival-Horror-FPS.md) for a practical overview of designing and building a first-person horror game in Unreal Engine, or open its [HTML edition](pages/Unreal-Survival-Horror-FPS.html).

## Repository files

- [index.html](index.html) — training library homepage and static-host entry point.
- [pages/Git-101.html](pages/Git-101.html) — interactive Git 101 course page.
- [pages/Git-101.md](pages/Git-101.md) — Git 101 course and command reference.
- [pages/Unreal-Survival-Horror-FPS.md](pages/Unreal-Survival-Horror-FPS.md) — Markdown source for the Unreal Engine survival horror FPS field guide.
- [pages/Unreal-Survival-Horror-FPS.html](pages/Unreal-Survival-Horror-FPS.html) — browsable HTML edition of the field guide.
- [assets/css/styles.css](assets/css/styles.css) — shared styles for the library and guides.
- [assets/js/home.js](assets/js/home.js) and [assets/js/app.js](assets/js/app.js) — homepage and course interactions.
- [.gitignore](.gitignore) — ignores build output, local tooling, secrets, and editor/operating-system files.
- [.gitattributes](.gitattributes) — keeps text files consistently normalized to LF line endings.
